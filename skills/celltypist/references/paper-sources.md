## Public-edition packaging

The installed personal skill was developed using reviewed paper-reading packets. This public edition retains the authored methods, workflows, scientific caveats, code provenance and available helper scripts, and links to the original publications. It omits publisher full-text transcriptions, page images and figure crops. Original conversion checks described in the provenance refer to the reviewed source packets, not to files included in this public repository. Obtain the relevant original source before making an exact figure, equation or table claim.

No private account links, uploaded research datasets or credentials are needed to use this skill. Runtime and biological-validation limitations remain those stated in the operational guide.
