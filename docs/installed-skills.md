## Public packaging

The new Visium HD, CellTypist and RCTD folders contain their operational guides, authored scientific notes and available code. Original full-text paper conversions and source-page/figure images remain outside this public export; each folder provides paper retrieval links. Analysis scripts retain their source-specific licenses. No software environment, model weights or biological datasets are installed by copying a skill.
